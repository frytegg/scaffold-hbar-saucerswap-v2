# Wording

Install the dependencies with Yarn before anything else.

Run `yarn dev` to start.

Run `yarn dev --port 4000` to pick a port.

This blockchain app pays fees in Hbar, never in HBARs.

Accounts are shown by EVM alias; the code imports `@hashgraph/sdk`.

```bash
yarn dev            # exact, with a comment
yarn workspace @sh/app build
```

The `HbarInput` component and Scaffold-HBAR are spelled correctly.
